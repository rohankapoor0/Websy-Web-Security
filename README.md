🌐 Websy — Smart Website Safety Checker

Websy is a lightweight web application that helps users quickly understand whether a website is safe, trustworthy, or potentially risky before they interact with it.
It focuses on clarity, accessibility, and real-world signals rather than fear-based warnings.

⸻

🚀 What is Websy?

Websy analyzes publicly available website signals and presents them in a simple, human-friendly way so users can make informed decisions online.

Instead of overwhelming users with technical jargon, Websy breaks down trust factors into an easy-to-understand summary.

⸻

🧠 Key Features
	•	🔍 Website Analysis
	•	Checks domain patterns, HTTPS usage, and basic site metadata
	•	📊 Trust Indicators
	•	Highlights positive and negative signals in a neutral, clear format
	•	🧩 Explainable Results
	•	Each result is explained in simple language
	•	🧑‍💻 Beginner-Friendly UI
	•	Designed for non-technical users
	•	⚡ Fast & Lightweight
	•	Quick checks with minimal friction

⸻

🛠️ Tech Stack

Frontend
	•	React
	•	TypeScript
	•	Modern UI components for accessibility and clarity

Backend
	•	Node.js
	•	Express
	•	REST APIs for website analysis

Other Tools
	•	Regex for pattern matching
	•	Modular architecture for easy scalability

⸻

🎯 Problem Websy Solves

Many users:
	•	Don’t know how to judge whether a website is trustworthy
	•	Fall for misleading or low-effort online stores
	•	Are confused by overly technical security tools

Websy bridges this gap by turning technical trust signals into human explanations.

⸻

👥 Who Is Websy For?
	•	Everyday internet users
	•	Students and first-time online shoppers
	•	Non-technical users who want clarity, not fear
	•	Anyone who wants a quick second opinion before interacting with a website

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
